# Foreign Exchange Currency Converter — Flutter Edition

**Flutter Mentorship Program — Final Project Brief**

You've already built this once in JavaScript. You handled the API calls, the conversion logic, the UI updates. Now the question is: can you build the same thing in Flutter — with proper architecture, clean state management, and code that holds up to a review?

This is a real-world class of app. Currency converters are a category that exists in every app store, and they require you to think carefully about API integration, async state, caching, error handling, and UX responsiveness. All of that is in scope here.

## 🚀 Getting Started

1. **Fork this repository** to your own GitHub account (button in the top right of the repo page)
2. **Clone your fork** locally:
   ```bash
   git clone git@github.com:YOUR-USERNAME/flutter-fx-converter.git
   cd flutter-fx-converter
   ```
3. Read [`docs/00-getting-started.md`](docs/00-getting-started.md) for the full setup walkthrough — registering an API key, initialising your Flutter project inside this repo, and your first commit
4. Read [`docs/01-overview.md`](docs/01-overview.md), then decide which tier you're attempting and read the matching doc
5. Use [`CHECKLIST.md`](CHECKLIST.md) to track your progress as you build

---

## 🧭 Choosing Your Tier

**Tier 1 (Base)** is required for everyone. It's a fully functional currency converter with live rates, BLoC state management, and a properly layered architecture. See [`docs/02-tier-1-base.md`](docs/02-tier-1-base.md).

**Tier 2 (Intermediate)** is optional and builds on Tier 1 — a rate history chart, multi-currency comparison, and a persisted favourites system. It adds 50 points on top of your Tier 1 score. See [`docs/03-tier-2-intermediate.md`](docs/03-tier-2-intermediate.md).

If you're unsure which to attempt, build Tier 1 completely and solidly first. A clean Tier 1 submission outscores a rushed, broken attempt at Tier 2.
