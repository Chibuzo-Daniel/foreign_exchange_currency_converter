# Ground Rules

Read this before you write a single line of code. Violating any of these can cap your grade regardless of how complete your feature set is.

- **You must use a live API** — hardcoded rates are not acceptable for either tier
- **`flutter_bloc` is required** — GetX, Provider, Riverpod, and `setState`-based logic are not permitted
- **External UI kits are not allowed** — build your own widgets
- **You may use `fl_chart`** for the chart (Intermediate only) — no WebView charts or image-based chart screenshots
- **AI-generated code is allowed as a reference**, but you must explain the data flow end-to-end in your verbal walkthrough
- **API keys must not be committed** to the GitHub repository — use a `.env` file or Flutter's `--dart-define`, and document it in your README
- **Late submissions lose 5 points per day**, up to a maximum of 15 points
